How it runs

The PC by the till runs the floor from one image; the kitchen screen reaches it on that PC's IP, port 8080. Data lives on a volume, settings come from the env-file, logs go to stdout.

docker build -t tableturn .
docker run -d --name tableturn -p 8080:8080 -v tableturn-data:/data --env-file .env tableturn
docker logs -f tableturn

The image is built from the Dockerfile you write.

Restart the container

This page cannot restart the container it is served from — you run the two commands. Press Before restart: the browser keeps a copy of every party on the list and the minutes each was quoted. Then run, in a terminal:

docker rm -f tableturn
docker run -d --name tableturn -p 8080:8080 -v tableturn-data:/data --env-file .env tableturn

Reload this page and press After restart: it reads every party again and says unchanged or names each difference. Change DEFAULT_QUOTE_MINUTES in the env-file before the docker run and the Rule book shows the new quote — no rebuild; the parties already on the list keep the quote they were given.
